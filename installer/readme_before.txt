Welcome to DiskAtlas Setup!

A cross-platform disk space analyzer with treemap visualization

Features:

- Scan local drives, folders, and removable media
- Treemap and tree views for exploring disk usage
- File type breakdown with customizable MIME categories
- Export scan results to CSV
- NTFS-aware scanning on Windows (where supported)
- Check for updates (Help menu)

System Requirements:
• Windows 10 or later (64-bit)
• At least 80 MB of free disk space

This installer will copy all necessary files including the GTK runtime libraries required for the application to run properly.
