Getting Started:
• Launch DiskAtlas from the Start Menu or Desktop shortcut
• Select a drive or folder to scan
• Explore results in the treemap or tree view
• Use Help > Check for Updates to get the latest version

Tips:
• Right-click items in the file tree for file operations
• Customize MIME categories in Settings for file-type views
• Export scan data to CSV from the File menu
